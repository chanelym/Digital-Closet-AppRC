# Digital Closet App 

Digital Closet App is a web-based application that allows users to build and manage their own digital wardrobe. Users can add clothing and shoe items, view their closet, edit existing items, and delete items they no longer need. Each item includes details such as its name, color, brand, image URL, and category, making it easy to organize and keep track of personal belongings. Users can also create an account, log in, and manage their own digital closet through a private profile.

## Features
User Authentication: Sign up and log in using Passport.js to access a personal digital closet.
Add Items: Add clothing and shoes using a form with fields for item name, color, brand, image URL, and category.
Browse Items: View all saved closet items along with their images and details.
Edit Items: Update existing item information whenever needed.
Delete Items: Easily remove items from your digital closet.
Personal Closet: Manage and organize your own collection of clothing and shoes.

## Tech Stack
Frontend: EJS, HTML, CSS, JavaScript, Bootstrap\
Backend: Node.js, Express.js\
Database: MongoDB Atlas with Mongoose\
Authentication: Passport.js

## What I Learned
Structuring an Express.js application using the MVC architecture, separating database operations, application logic, and user interface components to create more organized and maintainable code.
Implementing CRUD functionality to create, view, update, and delete closet items using MongoDB and Mongoose.
Working with EJS to render dynamic content and display item information.
Using Passport.js to implement user authentication, handle login functionality, and provide users with access to their personal closets.

## Installation

1. Clone repo
2. run `npm install`

## Usage

1. run `node server.js`
2. Navigate to `localhost:8080`
3. Create an account or log in to start building your digital closet!
